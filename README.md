# CV. Marina Jaya Internusa

Halaman profil satu file untuk CV. Marina Jaya Internusa, pemasok tali tambang (PP, polyester, nylon, manila, HMPE).

## Isi data kontak

Buka `index.html`, cari baris `const KONTAK` di dekat bagian bawah, lalu isi alamat, telepon, WhatsApp (format `6281234567890`), email, dan jam kerja. Baris yang dibiarkan kosong tidak ditampilkan, dan tombol WhatsApp muncul otomatis setelah nomornya diisi.

## Tayang lewat GitHub Pages

1. Unggah `index.html` ke repositori.
2. Buka Settings, lalu Pages.
3. Pilih branch `main` dan folder `/ (root)`, lalu simpan.
4. Alamat situs muncul di halaman yang sama dalam beberapa menit.
